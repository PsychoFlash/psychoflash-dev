# PSYCHOFLASH — Visual Content Engineering

**psychoflash.dev** — The living, self-learning portfolio of Orian Edelenyi / אדלני הפקות

---

## Stack

- **React 18** + **TypeScript** + **Vite 5**
- **Framer Motion** — adaptive layout animations
- **Tailwind CSS v3** — utility-first styling
- **Web Audio API** — generative ambient sound (zero audio files)
- **Canvas 2D API** — synaptic neural mesh background

## Neural Systems

| System | File | Description |
|--------|------|-------------|
| Neuro Profiler | `src/hooks/useNeuroMind.ts` | Behavioral learning engine (broadcast/hitech/events/creative) |
| Synaptic Canvas | `src/components/SynapticCanvas.tsx` | Force-directed neural mesh, 60fps |
| Adaptive Text | `src/components/AdaptiveText.tsx` | Content mutates per visitor profile |
| Hive Mind | `src/components/HiveMind.tsx` | Collective intelligence widget |
| Audio Engine | `src/hooks/useWebAudio.ts` | Generative synthesized audio |
